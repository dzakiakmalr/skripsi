Master Notebook — Prediksi Stunting Balita dengan XGBoost & LightGBM¶

Notebook ini merupakan penggabungan end-to-end seluruh tahap eksperimen skripsi dalam satu alur terpadu: loading data mentah, EDA, cleaning, preprocessing, pemodelan baseline, penanganan ketidakseimbangan kelas (SMOTE-ENN), hyperparameter tuning, hingga evaluasi dan perbandingan akhir model.

Alur pipeline:

Raw Data (Excel) → EDA → Cleaning → Label Encoding → Split 80:20 (stratified)
                                        │
                    ┌───────────────────┴────────────────────┐
              Baseline (default)                     SMOTE-ENN (hanya train) → GridSearchCV
                    │                                            │
                    └──────────→ Evaluasi pada Test Set Murni ←──┘
                          (Accuracy, Precision, Recall, F1, ROC-AUC, Confusion Matrix)

Prinsip metodologi utama:

  1. Anti-data-leakage — test set (X_test/y_test) tidak pernah disentuh proses resampling/tuning; hanya dipakai untuk evaluasi akhir. Integritas dijaga snapshot + assert.
  2. Kolom turunan dibuang (Weight for Age, Z-Score, dll.) karena menurunkan label target.
  3. Kelas positif = Stunted (1) — Recall & F1 kelas ini menjadi tolok ukur utama (false negative = balita stunting terlewat intervensi).
  4. Reproducibility — seluruh proses stokastik memakai random_state=42.

Catatan efisiensi: seluruh data dialirkan langsung melalui variabel DataFrame di memori (df → df_clean → X/y → X_train/X_test), tanpa file perantara antar tahap.

3. Data Cleaning & Outlier Handling (Perbaikan Kolom Weight dan Penanganan Missing Values)¶

Bagian ini membersihkan data mentah menjadi data siap-pakai secara langsung di memori (df → df_clean), tanpa menyimpan/memuat file perantara. Tahapan:

  1. Perbaikan kolom Weight — kerusakan akibat auto-conversion Excel (datetime → desimal).
  2. Penanganan outlier Weight — koreksi nilai skala gram & penghapusan nilai mustahil.
  3. Penanganan missing value pada Age (Month) dan Weight for Height.

Catatan: df (data mentah) sengaja dibiarkan utuh sebagai pembanding before/after.

3.1 Perbaikan Kolom Weight¶

Kolom Weight tercampur 3 tipe data akibat auto-conversion Excel:

  • datetime → nilai desimal asli (misal 2025-02-08 → 8.2, yaitu format day.month, umum di locale Indonesia/Eropa),
  • int / float / str numerik → dikonversi ke float.

Aturan konversi datetime: float(f"{day}.{month}").

In [18]:
print("Sebelum perbaikan — tipe data per nilai pada kolom Weight:")
print(df["Weight"].map(type).value_counts())

# Fungsi konversi nilai Weight campuran tipe menjadi float (kg)
def fix_weight_value(x):
    if isinstance(x, datetime):            # tanggal Excel → desimal asli (format day.month)
        return float(f"{x.day}.{x.month}")
    if isinstance(x, bool):
        return float(x)
    if isinstance(x, (int, float)):        # numerik → float
        return float(x)
    if isinstance(x, str):                 # string numerik → float
        return float(x.strip())
    return np.nan                          # tipe tak dikenali → NaN

# Terapkan perbaikan pada salinan data (df mentah tetap utuh sebagai pembanding)
df_clean = df.copy()
df_clean["Weight"] = df_clean["Weight"].apply(fix_weight_value)
print("\nDtype Weight setelah konversi:", df_clean["Weight"].dtype)
print("Jumlah NaN baru pada Weight:", df_clean["Weight"].isna().sum())

Penanganan Outlier Weight¶

Validasi menemukan dua jenis nilai di luar rentang wajar:

  1. Nilai skala gram (2800, 2900, 3000, 3085, 3100) — berat bayi baru lahir yang tercatat dalam satuan gram (2,8–3,1 kg adalah berat lahir normal). Perbaikan: bagi 1000.
  2. Nilai 91 — mustahil secara biologis untuk balita dan nilai aslinya tidak dapat dipastikan. Karena hanya 1 baris, baris ini dihapus (drop) daripada ditebak.

3.3 Penanganan Missing Value¶

Strategi: drop baris (bukan imputasi).

  • Age (Month) — 2 nilai hilang (0,005% dari 40.071). Usia adalah fitur numerik kunci; imputasi median/mean akan menyuntikkan nilai sintetis yang tidak berasal dari pengukuran, sedangkan drop hanya kehilangan data yang dapat diabaikan → drop.
  • Weight for Height — 5 nilai hilang. Kolom ini adalah fitur turunan yang sesuai metodologi justru akan dibuang saat feature selection (anti-leakage, Bagian 4), sehingga imputasi tidak memberi manfaat apa pun bagi pemodelan → drop.

4. Preprocessing & Data Splitting (Label Encoding & Split 80:20 Sebelum Resampling untuk Mencegah Data Leakage)¶

Tahap persiapan data sebelum pemodelan:

  1. Feature selection — hanya memakai 4 fitur mentah (Gender, Age (Month), Weight, Height); kolom turunan dibuang untuk mencegah data leakage.
  2. Label encoding — Gender (M → 0, F → 1) dan target Height for Age (Not Stunted → 0, Stunted → 1).
  3. Train-test split 80:20 stratified (random_state=42).

Urutan ini kritikal: split dilakukan sebelum resampling (SMOTE-ENN di Bagian 6) agar test set benar-benar mewakili distribusi data asli dan tidak pernah tersentuh proses resampling — inilah kunci pencegahan data leakage.

4.1 Feature Selection & Data Leakage¶

Dataset memiliki kolom turunan: Weight for Age, Z-Score W/A, Z-Score H/A, Weight for Height, Z-Score W/H.

Kolom-kolom ini wajib dibuang karena merupakan hasil perhitungan yang menurunkan label target (Height for Age). Contoh: target adalah hasil klasifikasi dari Z-Score H/A (anak dikategorikan Stunted bila H/A Z-score < −2). Bila kolom turunan ikut menjadi fitur, model hanya akan "mencontek jawaban" dari rumus yang sudah ada, sehingga performa menjadi semu dan tidak mencerminkan kemampuan prediksi dari data fisik mentah.

Variabel independen yang dipakai hanyalah 4 fitur mentah: Gender, Age (Month), Weight, Height.

PERHATIAN PENTING — Titik Kunci Anti-Data-Leakage¶

Mulai titik ini, X_test dan y_test TIDAK BOLEH disentuh oleh proses resampling apa pun (SMOTE, ENN, SMOTE-ENN, oversampling/undersampling lain), dan TIDAK BOLEH dipakai untuk fitting scaler/imputer, feature selection, maupun hyperparameter tuning.

  • SMOTE-ENN hanya diterapkan pada X_train/y_train (Bagian 6).
  • X_test/y_test dibiarkan murni — hanya disentuh saat .predict() dan evaluasi — sehingga metrik mencerminkan performa pada data yang belum pernah dilihat model.
  • Integritas dijaga dengan snapshot (X_test_snapshot/y_test_snapshot) + assert yang diperiksa ulang di Bagian 6, 7, dan 8.

Ringkasan¶

  • Data mentah 40.071 × 11 → bersih 40.064 × 11 (7 baris dihapus: 1 outlier Weight=91, 2 missing Age (Month), 5 missing Weight for Height — 1 baris tumpang tindih; 5 nilai gram dikoreksi menjadi kg).
  • X: 4 fitur mentah (Gender 0/1, Age (Month), Weight, Height); y: Stunted=1, Not Stunted=0.
  • Split 80:20 stratified (random_state=42) → train 32.051 / test 8.013.
  • Kolom turunan ber-leakage dibuang; snapshot test set disiapkan untuk validasi anti-leakage.

# Helper evaluasi tunggal: fit (terukur) + prediksi + seluruh metrik + confusion matrix
def evaluate_on_test(name, model, X_tr, y_tr):
    t0 = time.perf_counter()                      # ukur waktu training
    model.fit(X_tr, y_tr)
    train_time = time.perf_counter() - t0

    y_pred = model.predict(X_test)                # test set murni, hanya untuk prediksi
    y_proba = model.predict_proba(X_test)[:, 1]   # probabilitas kelas positif (Stunted)

    tn, fp, fn, tp = confusion_matrix(y_test, y_pred, labels=[0, 1]).ravel()
    metrics = {
        "model": name,
        "accuracy": accuracy_score(y_test, y_pred),
        "precision": precision_score(y_test, y_pred, pos_label=POS_LABEL),
        "recall": recall_score(y_test, y_pred, pos_label=POS_LABEL),
        "f1_score": f1_score(y_test, y_pred, pos_label=POS_LABEL),
        "roc_auc": roc_auc_score(y_test, y_proba),
        "tn": tn, "fp": fp, "fn": fn, "tp": tp,
        "train_time_s": train_time,
    }
    return metrics, y_pred, y_proba

6. Handling Class Imbalance (SMOTE-ENN)¶

Bagian ini menerapkan teknik hybrid resampling SMOTE-ENN untuk menangani ketidakseimbangan kelas (mild imbalance 40:60) sekaligus membersihkan noise akibat class overlapping.

Aturan kritis anti-data-leakage:

  • SMOTE-ENN HANYA diterapkan pada X_train/y_train.
  • X_test/y_test tidak disentuh sama sekali — divalidasi eksplisit dengan assert terhadap snapshot (Bagian 4) bahwa ukuran & isinya tidak berubah.

Urutan yang benar: split (Bagian 4) → SMOTE-ENN pada training set → tuning (Bagian 7) → prediksi pada test set murni (Bagian 8).

7. Hyperparameter Tuning (GridSearchCV dengan StratifiedKFold)¶

Tuning dilakukan pada data training hasil SMOTE-ENN (X_train_resampled/y_train_resampled) menggunakan GridSearchCV + StratifiedKFold.

Kunci anti-data-leakage:

  • Hyperparameter tuning hanya di dalam training set (cross-validation di atas data resampled), tidak pernah melihat test set.
  • Evaluasi final memakai X_test/y_test asli — sama persis dengan baseline (Bagian 5).

Grid yang di-tuning:

  • XGBoost: n_estimators, max_depth, learning_rate, gamma.
  • LightGBM: n_estimators, max_depth, learning_rate, num_leaves.

Scoring CV = F1 kelas positif (Stunted=1), konsisten dengan fokus metodologi (recall/F1 kelas minoritas lebih penting daripada accuracy).

7.1 Setup Grid & Cross-Validation¶

StratifiedKFold (5 fold, shuffle, random_state=42) menjaga proporsi kelas di tiap fold selama tuning.

Catatan metodologi (batasan): SMOTE-ENN diterapkan sekali pada training set (Bagian 6), lalu GridSearchCV dijalankan di atas data yang sudah resample. Artinya sampel sintetis dapat terpecah antar fold CV, sehingga skor F1 CV cenderung sedikit optimistik. Test set tetap murni (dicek assert), jadi metrik final tetap valid; yang berisiko hanya ketepatan pemilihan hyperparameter. Ini dicatat sebagai batasan metodologi (bukan leakage).

8.6 Panduan Interpretasi (Fokus Recall & F1 Kelas Stunted)¶

  • Recall (Stunted) = proporsi balita stunting yang berhasil dideteksi model. Nilai rendah → banyak false negative → anak stunting terlewat intervensi. Ini metrik terpenting penelitian ini.
  • Precision (Stunted) = ketepatan saat model memprediksi stunting (menekan false positive).
  • F1 (Stunted) = rata-rata harmonik precision & recall; tolok ukur keberhasilan SMOTE-ENN dalam menyeimbangkan deteksi kelas minoritas.
  • Jangan menyimpulkan model "terbaik" dari accuracy semata — accuracy bisa tinggi meski model gagal mendeteksi banyak kasus stunting (accuracy paradox).

Poin analisis utama:

  1. Dampak SMOTE-ENN: recall kelas Stunted naik tipis (XGBoost 0.9401 → 0.9454; LightGBM 0.9454 → 0.9494; FN turun 194→177 dan 177→164), dengan trade-off precision/accuracy turun tipis — sesuai karakter data yang hanya mild imbalance (40:60).
  2. Gap CV vs Test: skor CV GridSearchCV (≈0.996) jauh di atas F1 test (≈0.945–0.951) — bukti bahwa CV pada data sintetis bersifat optimistik; skor CV bukan jaminan generalisasi.
  3. XGBoost vs LightGBM: performa sangat dekat; LightGBM sedikit unggul di recall/F1 pada kedua skenario dan lebih cepat dalam training.
  4. Keterbatasan (diakui eksplisit): baseline tidak di-tuning (perbandingan belum sepenuhnya apple-to-apple), belum ada uji signifikansi (McNemar), dan pengukuran waktu training bersifat indikatif (satu kali pengukuran per mesin).
